# LibaryWeach — Система автоматизации библиотек

**LibaryWeach** — это веб-приложение для библиотекарей, разработанное на платформе **Oracle APEX**. Система помогает уйти от бумажного учёта и таблиц Excel, переводя работу современной библиотеки в удобный цифровой формат.

## Главные функции системы
*   **Каталог книг:** Удобный поиск по авторам, жанрам и названиям.
*   **Учёт читателей:** Электронные карточки пользователей с историей взятых книг.
*   **Контроль выдачи:** Фиксация дат выдачи и автоматическое отслеживание должников.

## Технологический стек
*   Oracle APEX 23.x / 24.x
*   Oracle Database (PL/SQL, SQL)
